## Project Overview

The **Podcast Guest Scheduling & Outline Builder** is a media production organizer designed to simplify the process of scheduling podcast interviews and preparing episode information.

The system allows podcast guests to select available interview slots and submit discussion topics and biography links. The show host can manage interview availability, review guest submissions, and generate a formatted, timestamped run-of-show production sheet.

The main actors involved in the system are:

- **Podcast Guest**
- **Show Host**
- **Calendar/Notification Service**
